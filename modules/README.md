# Índice de módulos

Cada módulo deve ser tratado como caixa-preta: responsabilidade, usuários, entradas, saídas, erros e operações proibidas.

Módulos previstos: `auth`, `accounts`, `remote`, `local`, `state`, `changes`, `planner`, `conflicts`, `download`, `upload`, `queue`, `coordinator`, `notifications`, `ipc`, `configuration`, `ui`.

A especificação detalhada completa está no pacote documental v0.1. A transposição ao repositório ocorre sem implementação do motor.
