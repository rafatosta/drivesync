# Casos de teste — configuração

Os testes exercitam seleção inválida, diretório inexistente ou não gravável,
normalização e sobreposição de caminhos, configuração concorrente e falhas.
Os testes de contas usam diretórios isolados e verificam a preservação de
metadados existentes. A validação do Documents portal real requer uma sessão
Flatpak apropriada.
