# Consulta de pastas remotas

Obter acesso autenticado para a conta selecionada, consultar metadados de
pastas via Drive API e converter os resultados validados. Retornar o token de
paginação ao chamador para navegar outras páginas; erros não representam uma
lista vazia bem-sucedida.

Referências: [files.list](https://developers.google.com/workspace/drive/api/reference/rest/v3/files/list)
e [busca de pastas](https://developers.google.com/workspace/drive/api/guides/search-files).
